BUILD
  source/build-vkd3d-gears.sh <patched demos dir> <out dir> x86_64 arm64ec
  The script compiles with clang -std=gnu11 -O2 -DNDEBUG and includes source/shim-gears/ ahead of the demos.
  shim-gears/ provides vkd3d_win32.h, vkd3d_windows.h and vkd3d_d3d12.h. These map vkd3d-proton's
  widl-generated headers to the mingw-w64 windows.h, dxgi1_4.h and d3d12.h, with WIDL_C_INLINE_WRAPPERS and
  FORCEINLINE=inline. It links with -static -s -mconsole -Wl,--no-insert-timestamp
  -ld3d12 -ldxgi -luser32 -lshell32 -lgdi32 -lm. The build ran under flock /home/flux/build-cache/build.lock.

MODIFICATIONS (source/vkd3d-gears-panplay.patch, "diff -ru orig src"; apply with patch -p1 -d <demos copy>)
  - gears.c:
    - Includes PanPlayHarness.h and shellapi.h.
    - assert() becomes a "DX12: FAIL gears.c:<line> <expr>" line followed by ExitProcess(1).
    - pph_on_present() runs after every present and quits once DX12TEST_SECS is reached.
    - pph_init("vkd3d-gears") parses the command line.
    - The window is 1280x720 instead of 300x300.
  - demo_win32.h: demo_swapchain_present() returns the Present HRESULT and uses pph_sync_interval()
    (default 0) instead of a fixed sync interval of 2.
  Rendering is unchanged: 3 instanced gears drawn with a smooth and a flat PSO, 3 swapchain buffers and a
  frame-latency waitable object. PanPlayHarness.h times the run and the fps average from the first Present.
