# 2026-10-21 v7 group A fixes, RC5-dev-v7G-A (NDK r30)

Scope: A06 (Mali-G52 r1, v7 JM) GPU job faults: bc_perf, occlusion_query, pipeline_stats,
large_draw, xfb, depth_bounds and the faulting part of tessellation.

## Decoding the v7E faults

Codes checked against the Mali exception list in the tree
(`src/panfrost/lib/kmod/mali_kbase_csf_registers.h`, shared with JM for >= 0x40)
and the kbase JM base events: 0x04 = BASE_JD_EVENT_TERMINATED (hard-stopped),
0x42 = JOB_READ_FAULT, 0x51 = INSTR_INVALID_ENC, 0x58 = DATA_INVALID_FAULT,
0x5b = IMPRECISE_FAULT.

- Atoms 1..5 failing with 0x04 are one chain: the queue warm-up submits its first
  vertex/tiler/compute chain through `kbase_kmod_job_submit_retry(..., 5)`; the logcat
  gaps (0.4, 0.8, 1.2, 1.6 s) are its retry delays. In every failing test that chain is
  `vkCmdResetQueryPool` alone: the precompiled `clear_query_result` compute job. After it
  the context's chains fail with JOB_READ_FAULT (the AS is unusable after the
  hard-stop), so nothing else in these tests is trustworthy.
- Tessellation (atom 19) and xfb (atom 13) die at their first query case, the same job.
- The only JM user of the uncached pool (`mempools.rw_nc`, BASE_MEM_UNCACHED_GPU) is the
  query availability array, which `clear_query_result` writes.
- bc_perf: `CreateQueryPool(TIMESTAMP)` hit UNREACHABLE on v7 (garbage
  reports_per_query) and `CmdWriteTimestamp2` was a stub.
- depth_bounds: the FS lowering passed a zero INTERNAL_CONVERSION to the depth
  LD_TILE; Bifrost rejects that (`prepare_iam_sysvals()` notes the same for depth input
  attachments). First fragment atom 0x51, its retries 0x58.

## Patches (patches/jm-v7-wip)

- 0020 (jm-v7 021): v6/v7 query availability from the cached pool
  (`PANVK_QUERY_UNCACHED=1` restores the uncached one for A/B); timestamp queries on
  v6/v7 through the v9 JM path (WRITE_VALUE SYSTEM_TIMESTAMP, PERMON, 1 report,
  timestampValidBits 64).
- 0021 (jm-v7 022): depth bounds LD_TILE gets the depth conversion via a new
  `ds.z_conv` graphics sysval on v6/v7.
