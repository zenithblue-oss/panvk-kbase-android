# 2026-10-21 v7J: robustness2 regression and vkd3d_heap image_heap (RC5-dev-v7J)

Tree: `/home/flux/src/mesa-v7J` (branch `v7J`), worktree of `/home/flux/src/mesa-v7I` at `f9b7291` (0006-0056) plus:

- **0057 (jm-v7 084)**: robustness2 null_descriptors on v7I: `txb_rgb=[0,0,0] a_txb=1.0` (passed on v7G-DI). 0056 bounds-checks non-bindless txf on buffers and returns the inverted hardware alpha out of bounds. The null texel buffer (`panvk_device::null_descs.texel`) is a 0-element R32_UINT view: every fetch is OOB, hardware alpha 0, so the shader returned 1. Now the alpha is inverted only when the view size is >= 1; a 0-element (null) view reads (0,0,0,0). robust_image_access2 tbuf cases use real views and are unchanged.
- **0058 (jm-v7 085)**: vkd3d_heap image_heap `output[1]=0x13570101 expected=0x13570202 index=500000` (also at 32767 with `PANVK_DI_TEX_MAX=65535`, so not the 16-bit count). 0x13570101 is the image at heap index 0 = lane 0's descriptor; the shader is `texelFetch(heap[nonuniformEXT(idx[i])])` with 4 lanes. Descriptors are written before recording, so not an update-after-bind issue. The Bifrost texture unit takes one index per warp, also from inactive lanes; nir_lower_non_uniform_access only makes the index uniform over the *active* lanes (lanes that left its loop keep their old index), so lane 1 got lane 0's slot. New pass `panvk_v7_lower_divergent_tex()` (before nir_lower_non_uniform_access, v6/v7): a tex with a divergent texture_offset/sampler_offset becomes a uniform loop (ballot of waiting lanes, read_invocation of the first one's index to all lanes, tex with all lanes active, keep result where the index matches, uniform break, cap 32 iterations). `PANVK_TEX_WATERFALL=0` restores the old lowering. Advertised 1M limits unchanged.

Not verified on device yet. If image_heap still fails with 0058, run with `PANVK_TEX_WATERFALL=0` for comparison.
