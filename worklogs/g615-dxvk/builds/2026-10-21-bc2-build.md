## Changes

- H8 (200): palette encoder for the ETC2/EAC transcoder (EAC: base fitted
  to the 8 BC4 palette values, (table, multiplier) candidates from a
  trained LUT, nearest modifier from a second LUT, exact clamped error over
  the palette; ETC2: 4 unpacked BC1 colours, flip heuristic, 3-table 1D
  luma search, H seeded from the BC1 endpoints, planar from palette
  moments). One pipeline per mode, mode/opts as spec constants 2/3,
  unrolled loops, no dynamically indexed per-block arrays, uvec2/uvec4
  loads and stores, 64-bit block addresses (LOW 197 z*slice overflow).
  PANVK_BC_LM_OPTS: 0x10000 planar, 0x20000 H, 0x40000 both flips,
  0x80000 all 8 ETC1 tables, bits 20-21 EAC candidates - 1. Default
  0x30000 (1 EAC candidate).
- M15 (201): spill dir list adds the Android app cache dir
  (/data/user/<user>/<pkg>/cache, from /proc/self/cmdline); an upload or
  BC -> BC copy covering every block skips read-back, zero fill and flush.
- H7 (202): PANVK_BC_BC6H defaults to exact (ASTC opt-in); MUTABLE UF16
  images stay exact (LOW 202).
- H6 (202): image view sets `pview.astc.hdr` from the shadow format after
  the format swap.
