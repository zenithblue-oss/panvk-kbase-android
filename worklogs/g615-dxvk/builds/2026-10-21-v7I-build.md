# 2026-10-21 v7I: fixes for the A06 v7G-DI failures (RC5-dev-v7I)

Tree: `/home/flux/src/mesa-v7I` (branch `v7I`), a worktree of `/home/flux/src/mesa-v7wip-order` at `13fec7f` (jm-v7-wip 0006-0053 in glob order on `ab7d630`) plus 3 new patches:

- **0054 (jm-v7 081)**: if-phi constants are now built before the if. `nir_imm_*()` inserts at the cursor, so a constant built after `nir_pop_if()` landed in the merge block *ahead of* the phi. When 0051 (jm-v7 080) switched the skipped-atomic value from `nir_undef` (which goes at the top of the impl) to `nir_imm_zero()`, the 0037 (jm-v7 035) fix-up loop `nir_foreach_phi(after)` stopped at the load_const and never found the phi. `phi(phi, 0)` stayed, so every guarded VS atomic returned 0 again:
  - vertex_stores iter0-5 `outv (1000,1000)`;
  - draw_params `rec[atomicAdd]` all at rec[0], which stalled (the test after `sampler` in suite order; it also hung on v7G, from the same guard).

  The guard now rewrites the uses and points the phi's then-source back directly. The same constant-after-pop_if pattern is fixed in the robust storage image ops (0035/jm-v7 048) and in the bindless image atomics (panvk_vX_nir_lower_descriptors.c).
- **0055 (jm-v7 082)**: the GS emulation zeroes each invocation's first output vertex slot (position, and for points the size and the stream-0 xfb count) before the shader body. The degenerate index fill points at that slot, and zero area does not cull a point. Since 0049 (jm-v7 078), direct-draw GS buffers come from the reused GPU-only pool rather than fresh zeroed desc BOs, so a culled triangle in POINT mode drew a stale vertex of an earlier draw. This is the likely cause of fill_mode `mismatch=2` (1 case; the regression from v7G). It is unconfirmed, because the run has no per-case lines.
- **0056 (jm-v7 083)**: robustImageAccess2 for uniform texel buffers (txf on a buffer, non-bindless). Bounds-check against txs; out of bounds, x = size, RGB = 0, and alpha = the inverted hardware alpha. This fixes robust_image_access2 tbuf_oob / tbuf_alias65537 (8 cases; hardware gave r32ui (0,0,0,0) and rgba8 (0,0,0,1.0)).

Device evidence: `device-runs/2026-10-21-a06-v7gDI/pulled/` (part1: fill_mode FAIL mismatch=2, vertex_stores FAIL, robust_image_access2 FAIL 8 tbuf cases; all else PASS through `sampler`).
