## How to run tests (RTL)

1. User starts the RTL session and Remote Debug Bridge. Do not drive RTL through Chrome.
2. `~/rtl-rdb/rdb` serves the web client on :8888. The adb port is in `/var/tmp/panvk/rtl/rdb-run.log`, usually `localhost:46523`.
3. PanProbe: use the autorun command (see `TEST_DEVICES.md`). PanPlay: launch via shortcut id, e.g. `builtin-d3d9-i686`.
4. APKs: `/var/tmp/panvk/rtl/PanProbe-dev-v9fix.apk`, `PanPlay-dev-v9fix.apk`. Driver: `/var/tmp/panvk/dist-v9fix` (BuildID `de4827a8`).
5. Update the credit log in `TEST_DEVICES.md` after every session (2 credits per 30 min).
